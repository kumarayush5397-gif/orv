# ORV — Gen Z Fashion

This is the v12-style ORV storefront with the supplied collection artwork installed.

## Product image order
1. Project ORV — Infinite Dimension Space Coat
2. Project ORV — Galaxy Night Coat
3. Normal Wear — Everyday Utility Set
4. Festival Wear — Festival Night Layer
5. Project Rasengan — Rasengan Shinobi Tee
6. Project Bankaii — Bankaii Blade Bomber
7. Project Lookism — Seoul Layered Street Set

All seven cards use the supplied full product-sheet images in `assets/products/`.

## Interaction
- Tap/click any product card to open the product details panel.
- The panel shows the image, price, colour selection, size selection, quantity and BUY NOW.
- Tap/click the large image inside the details panel to open the fullscreen image zoom.
- In fullscreen zoom the selected image stays crisp while the website underneath is blurred/dimmed.
- Responsive layout works on desktop and phone screens.

Open `index.html` to run it locally.
